# CodeAlpha__ImageGallery

# 📸 Image Gallery – CodeAlpha Internship Task 1

## 📌 About the Project

This is a simple and responsive Image Gallery website developed as part of my **CodeAlpha Frontend Development Internship**.

The project displays a collection of beautiful images in a grid layout. Users can browse images, filter them by categories, and view selected images in a larger lightbox view.

## 🚀 Features

- Responsive image gallery layout.
- Category-based image filtering.
- Lightbox view for larger images.
- Next and Previous image navigation.
- Keyboard navigation using arrow keys.
- Close lightbox using the Escape key.
- Smooth hover effects and transitions.
- Mobile-friendly design.

## 🛠️ Technologies Used

- **HTML5** – To create the structure of the gallery.
- **CSS3** – To design the layout, hover effects and responsive interface.
- **JavaScript** – To handle image filtering, navigation and lightbox functionality.

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in your browser.
4. Click on any image to open it in lightbox view.
5. Use Next and Previous buttons to navigate between images.
6. Select category buttons to filter images.

**Note:** An active internet connection is required because images are loaded from Unsplash.
